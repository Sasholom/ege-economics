Экономическая задача: шпаргалка

Проценты и коэффициент b

Если долг $S$ вырос на $r\%$, он стал $S + \dfrac{r}{100}S = S\left(1+\dfrac{r}{100}\right)$. Множитель в скобках обозначаем буквой $b$:

$$b = 1 + \dfrac{r}{100}$$

10% → $b = 1{,}1$; 12,5% → $b = 1{,}125 = \dfrac{9}{8}$; 3% в месяц → $b = 1{,}03$. После $n$ начислений без выплат долг равен $Sb^n$.

Почти все задачи на кредит решаются одной таблицей: «долг с процентами — платёж — остаток». Каждая следующая строка начинается с остатка предыдущей, умноженного на $b$.

Три схемы платежей

Аннуитет — все платежи равны $x$. Долг после последнего платежа равен нулю:

$$Sb^n = x\left(b^{n-1}+\dots+b+1\right) = x\cdot\dfrac{b^n-1}{b-1}$$

Дифференцированные платежи — долг каждый раз уменьшается на одну и ту же величину $\dfrac{S}{n}$. Платёж = проценты на текущий долг + $\dfrac{S}{n}$. Сумма всех выплат:

$$S + \dfrac{r}{100}\cdot S\cdot\dfrac{n+1}{2}$$

Долг по таблице — остатки на каждую дату заданы. Платёж месяца: долг до начисления $\times\, b$ минус следующий остаток. Сумма выплат:

$$b\cdot(\text{сумма долгов до начисления}) - (\text{сумма остатков после платежей})$$

Сумма столбца «Платёж» = $b\cdot S\cdot\dfrac{n+1}{2} - S\cdot\dfrac{n-1}{2}$. Здесь пригодились суммы $1+2+\dots+n = \dfrac{n(n+1)}{2}$.

Прогрессии

Арифметическая: $a_n = a_1 + (n-1)d$, сумма $S_n = \dfrac{a_1+a_n}{2}\cdot n$.

Геометрическая: $b_n = b_1q^{n-1}$, сумма $S_n = \dfrac{b_1(q^n-1)}{q-1}$.

В задачах на кредит чаще всего нужна сумма $1 + b + b^2 + \dots + b^{n-1} = \dfrac{b^n-1}{b-1}$.

Оптимизация

Записываем величину, которую надо сделать наибольшей или наименьшей, через одну переменную. Ищем производную, её нули и знаки.

Если функция линейная, производная постоянна: максимум на краю отрезка. Значит, выгоднее отдать всё одному варианту — тому, что даёт больше на единицу ресурса.

Если ответ — количество (номера, приборы), проверяем целые точки рядом с найденной.

Как решать каждый тип

  1. Тип 1. Кредит: найти срокПлатим максимум каждый период и ведём таблицу «долг с % — платёж — остаток», пока долг с процентами не станет меньше платежа. Последний платёж неполный — он тоже считается.
  2. Тип 2. Кредит: найти ставкуЗаписываем равенство для последней строки таблицы через $b$, например $Sb^2 = x(b+1)$. Находим $b$, затем $r = 100(b-1)$.
  3. Тип 3. Кредит: найти суммуИз условия аннуитета: $S = \dfrac{x(b^n-1)}{b^n(b-1)}$. Для двух лет: $S = \dfrac{x(b+1)}{b^2}$.
  4. Тип 4. Кредит: найти платёжПлатёж: $x = \dfrac{Sb^n(b-1)}{b^n-1}$. Для двух лет $x = \dfrac{Sb^2}{b+1}$, для трёх $x = \dfrac{Sb^3}{b^2+b+1}$.
  5. Тип 5. Кредит: разница переплатСчитаем общую сумму выплат по каждой схеме отдельно и вычитаем. Переплата = выплаты − кредит.
  6. Тип 6. Кредит: долг задан таблицейПлатёж месяца = долг до начисления $\times\, b$ − следующий остаток. Сумма выплат = $b\cdot$(сумма долгов до начисления) − (сумма остатков после платежей).
  7. Тип 7. Кредит: дифференцированные платежиДолг каждый раз уменьшается на $\dfrac{S}{n}$. Сумма выплат: $S + \dfrac{r}{100}S\cdot\dfrac{n+1}{2}$. Самый большой платёж — первый.
  8. Тип 8. Кредит: нестандартные схемыСтроим таблицу строго по условию: что растёт, что выплачивается, какие данные неизвестны. Затем одно уравнение на неизвестное.
  9. Тип 9. ВкладыВклад за период умножается на $b$. Каждый взнос или снятие — отдельное слагаемое со своей степенью $b$ (сколько раз на него начислили проценты).
  10. Тип 10. ОптимизацияЦелевая функция одной переменной → производная → нули и знаки. Если ответ целый — проверяем соседние целые точки. Линейная функция — максимум на краю.
  11. Тип 11. Нестандартные задачиВводим переменные, переводим условие в уравнения и неравенства. Отношения и проценты часто сокращают неизвестную величину.
