# Экономическая задача — ЕГЭ профиль

50 экономических задач (кредиты, вклады, оптимизация) в 11 типах: теория, пошаговые решения с пояснениями, проверка ответа и ИИ-репетитор.

## Что есть на сайте

- 50 задач с теорией, решениями по строкам и проверкой ответа; поиск и фильтры (нерешённые, решённые, на повторении).
- **Похожая задача** — ссылка на задачу того же типа с «Решу ЕГЭ» (условие открывается там) и проверка ответа здесь. Индекс номеров и ответов — `data/similar.json`, обновить: `python3 tools/sdamgia_index.py`.
- **Повторение**: задачи с ошибкой или открытым решением возвращаются через 1, 3 и 7 дней.
- Серия дней, достижения, отчёт по ссылке для репетитора/родителей (`report.html`), шпаргалка для печати в PDF (`cheatsheet.html`).
- Тёмная тема.

## ИИ-репетитор

Кнопка «Решать с репетитором» у задачи или «Своя задача с репетитором» вверху страницы.
Репетитор сначала задаёт пару вопросов по теории, оценивает уровень (Начинающий / Базовый / Уверенный / Сильный) и ведёт по задаче шагами под этот уровень. Оценки сохраняются в «Мой уровень».

Два режима (переключаются в «Настройках ИИ»):

- **Встроенный ИИ** — запросы идут через сервер на Vercel (`proxy/`), ключ хранится там в переменных окружения. На сайте нужно только кодовое слово.
- В чат можно прислать фото решения и диктовать голосом (Chrome, Safari).
- **Свой ключ** — любой сервис с API, совместимым с OpenAI (`/chat/completions`). Ключ хранится только в браузере.

### Сервер на Vercel (`proxy/api/chat.js`)

Проект `ege-economics-ai`, адрес `https://ege-economics-ai.vercel.app/api/chat`. Переменные окружения (Settings → Environment Variables):

| Переменная | Что это |
|---|---|
| `AI_API_KEY` | ключ сервиса ИИ |
| `AI_BASE_URL` | адрес API, например `https://openrouter.ai/api/v1` |
| `AI_MODEL` | модель, например `openai/gpt-4o-mini` |
| `ACCESS_CODE` | кодовое слово для сайта (регистр не важен) |
| `DAILY_LIMIT` | необязательно, запросов в сутки (по умолчанию 300, счёт приблизительный) |

После изменения переменных нужен Redeploy.

## Как править

Контент — в `content.py`. После правок:

```bash
python3 build.py
```

Скрипт пересоберёт `index.html`. Оформление — `assets/style.css`, логика и подсказка для ИИ — `assets/app.js`.
